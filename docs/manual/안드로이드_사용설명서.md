# 큐하치 X 안드로이드판 사용 설명서 (메뉴로 하는 법)

대상: **Kyuhachi X v0.6.0** · Retroid Pocket Nova
ini 파일은 고치지 않습니다. **전부 큐하치 메뉴만으로** 하는 방법이고, 메뉴로 안 되는 건 「지금은 메뉴로 안 됨」이라고 적었습니다(맨 아래 표).

- 스샷은 `img/` 폴더. **화면 효과(셰이더·주사선·마스크·번짐·빛 번짐·곡면)와 FPS 표시를 모두 끈 상태**로 찍었습니다(이번 개정 샷은 전부 효과 끈 기본값).
- 「확인함」 = 노바에서 최종 APK(t653 / 샷 중 일부는 같은 화면의 t652)로 실제로 눌러 본 것. 「미확인」 = 이번에 못 해 본 것. 「이전 빌드 샷」 = 기능은 있으나 이번에 다시 못 찍어 앞선 빌드(t6xx)의 샷을 쓴 것(화면 모양은 같지만 맨 위 버전 표기가 다를 수 있음).
- 버튼 이름은 노바 기준 **A / B / X / Y**(retro 배치: A=오른쪽 · B=아래 · X=위 · Y=왼쪽)로 통일했습니다. 「조작 안내」 화면과 아래 줄 도움말은 5b-4 부터 노바 표기(→(A) ↓(B) ←(Y) ↑(X))로 나옵니다. 아직 ○ × □ △ 로 적힌 안쪽 화면이 남아 있으면 **○=A · ×=B · □=Y · △=X** 로 읽으세요.
- 앱 이름이 **Kyuhachi X** 로 바뀌었고 새 로고(九八)가 앱 아이콘입니다. 새 패키지라 **옛 큐하치 앱과는 별개 앱**으로 같이 설치됩니다(옛 앱은 지우지 않아도 됨). **옛 앱의 설정은 새 앱으로 옮겨지지 않고 새로 시작합니다**(안드로이드; Windows 판만 세이브를 자동 복사).

## 0. 메뉴 조작법
글자 메뉴(PC-98 부트로더 화면)는 **십자키(↑↓←→) · A=결정 · B=취소 · SELECT=부가 메뉴**로 움직입니다(키보드의 Enter·Esc·Tab도 같음). 화면 맨 아래 줄에 지금 쓸 수 있는 키가 늘 표시됩니다.
- 탭이 있는 화면(작품 선택, 패드 설정)은 **Q·E(패드는 L·R 어깨 버튼)** 로 탭을 넘깁니다.
- 항목은 화면을 손가락으로 눌러도 됩니다. **「예/아니오」 확인창도 터치로 누를 수 있습니다(빌드 4 부터)** — 십자키 ←→ 로 고르고 A 로도 됩니다.
- 화면 오른쪽 가장자리의 청록색 작은 탭은 큐하치가 아니라 기기(Pulse) 성능 패널입니다.

## ① 처음 실행
1. 앱(Kyuhachi X)을 처음 실행하면 **「모든 파일에 액세스」 안드로이드 권한 화면**이 먼저 뜹니다(확인함). 앱 이름 「Kyuhachi X」 아래 **「모든 파일 관리 허용」** 스위치를 **사용자가 직접 켜고** 뒤로 돌아오면 `Kyuhachi\` 폴더를 읽습니다(컴퓨터·adb 명령은 필요 없음. 개발 시험 기기에서만 adb 로 미리 허용해 두었고, 일반 사용자는 이 화면 안내대로 켜면 됩니다). ![](img/600_main_5b3.png) *(파일 이름은 main 이지만 실제 내용은 이 권한 화면입니다)*
2. 허용 뒤 앱을 다시 열면 잠시 뒤 **메인메뉴**가 뜹니다. 위 오른쪽 구석에 버전 `v0.6.0-t653`(5b-4)이 보이면 정상. 메뉴 순서(여섯 줄, 확인함): **게임 시작 / 작품 선택 / 설정 / 세이브 관리 / 부가 / 끝내기**. 예전의 「화면 설정」「소리·패드·배속 설정」 줄은 **설정** 한 줄로 합쳐졌습니다(⑤). ![](img/930_main_5b4.png) 위 제목줄 「Kyuhachi X v0.6.0-t653」, 오른쪽 위 「v0.6.0-t653」(확인함).
3. 새 시작 로고(九八 글자 그림)는 Windows 판에서 그림이 만들어지는 것까지만 확인했고 **노바에서 로고 화면을 찍어 보진 못했습니다(미확인)**.
4. 폴더 구조: 내부 저장소 `Kyuhachi\` 안에 `games`(게임) · `fonts`(글꼴) · `여기에_넣으세요.txt`. SD카드를 쓰면 SD 맨 위 `Kyuhachi\games` 도 작품 목록에 같이 나옵니다. (폴더 목록 화면은 안드로이드 파일 앱이라 스샷 없음)
5. 처음 목록이 뜰 때 **분류가 확실하지 않은 작품은 「미분류」 탭으로 옮겨졌다는 안내**가 한 번 뜹니다(예: 「분류가 확실하지 않은 작품 13 (미분류 탭으로 옮김)」, 확인함 — 아래 ③ 참고).

## ② 게임 넣기
1. **PC에서 복사**: 기기를 USB로 연결 → `내부 저장소\Kyuhachi\games\<게임이름>\` 폴더를 만들고 그 안에 이미지(.fdi .hdi .hdm .d88 …)를 넣습니다. **폴더 하나 = 작품 하나**이고, 디스크가 여러 장이면 같은 폴더에 같이 넣습니다(예: `games\nadia\` 안에 hdi 1개 + hdm 2개). *(PC·파일 앱 작업이라 스샷 없음)*
2. **SD카드**: SD 맨 위 `Kyuhachi\games\` 에 같은 방식으로 넣습니다. *(스샷 없음)*
3. 앱에서 **메인메뉴 → 작품 선택**을 열어 새 작품이 보이면 성공입니다. **탭 네 개 — 한글판 / 원판 / 미분류(개수) / 전체** 를 Q·E 로 넘깁니다(확인함). 제목·원제·연도 등으로 정렬은 D. ![](img/920_pick_tab1.png)
4. 목록에 안 보이면 → ③의 「게임 폴더 다시 검색」.

## ③ 게임 등록 (작품 추가 메뉴) · 미분류 탭 · 언어 지정
작품 선택 화면의 **한글판 탭** 맨 아래 **「+ 작품 추가」**로 들어갑니다(t605b 에서 확인, 이번엔 다시 안 찍음 — **이전 빌드 샷**).
1. 작품 선택 → 한글판 탭 → 맨 아래 「+ 작품 추가」에 커서를 놓습니다. ![](img/110_tab_hangul.png)
2. A를 누르면 「작품 추가」 화면이 열립니다. 오른쪽에 지금 게임 폴더 위치와 「추가 0 · 있음 39 · 건너뜀 0 · 불가 0」 같은 결과가 나옵니다. ![](img/113_add_screen.png)
3. 항목이 하는 일(화면 아래 설명 줄에도 나옵니다):
   - **이미지 파일 고르기** — 고른 이미지 파일들을 **한 작품으로 등록**합니다(여러 장 가능). 형식은 확장자가 아니라 파일 머리로 판정합니다. (**이 항목으로 다중 디스크를 등록해 보는 시험은 미확인**)
   - **폴더 고르기** — 고른 폴더를 한 작품으로 등록합니다.
   - **게임 폴더 지정** — 큐하치가 작품을 찾아보는 **큰 폴더(games)** 의 위치를 바꿉니다.
   - **게임 폴더 다시 검색** — 폴더를 다시 훑어 새로 넣은 게임을 목록에 올립니다.
   - **게임 폴더 해제** — 지정한 게임 폴더를 풉니다.
   - **방금 추가한 작품 언어 지정** — 방금 등록한 작품의 언어(한글판/원판)를 정합니다(추가한 게 없으면 회색).
4. **미분류 탭**: 언어(한글판/원판)가 확실하지 않은 작품은 「미분류」 탭에 모입니다(위 920 샷의 「미분류(13)」). 거기서 작품을 골라 **부가(SELECT/Tab) → 이 작품 설정 → 언어 지정**으로 한글판/원판을 정해 주면 해당 탭으로 갑니다. 이 「언어 지정」 줄이 있는 화면은 확인함(아래 ③-6), 실제로 값을 바꿔 작품이 탭을 옮기는 것은 이번엔 **미확인**(이전 빌드 샷: `377_lang.png`).
5. **작품마다 쓰는 키**(작품 선택 화면): A=시작 · **SELECT/Tab=부가 메뉴** · **S=실행 방법(편집)** · **D=정렬** · ←→=실행 방법 고르기.
6. **부가 메뉴(바뀐 자리, 확인함)** — 일곱 줄: **디스크 정보 / 부팅 시퀀스 다시 보기 / 조작 안내 / 정보·라이선스 / 적용값 보기(값·출처 표) / 이 작품 설정 ▸ / 원본 디스크로 초기화**. ![](img/803_extra_main.png)
   - **이 작품 설정 ▸** 를 열면 **언어 지정 / 즐겨찾기(☆ 끔 ↔ ★ 켬)** 두 줄이 있습니다(예전엔 부가 메뉴 안에 따로 있던 것). B 로 나오면 커서가 「이 작품 설정」에 돌아와 있습니다. ![](img/806_thisgame_fav_sel.png)
   - **시스템 디스크만 부팅**은 부가 메뉴에서 빠지고 **메인메뉴 「게임 시작」 아래**로 옮겨졌습니다(아래 ③-7).
   - **적용값 보기**: 이 작품의 각 항목 최종값과 그 **출처(game.ini·DB·계산 등)**, 덮어쓴 값을 표로 봅니다. ![](img/911_vals.png)
   - 「정보·라이선스」 화면(확인함, 맨 위에 앱 이름·버전 「Kyuhachi X v0.6.0-t653」): ![](img/932_about_5b4.png)
7. **게임 시작(확인함)**: 메인메뉴 「게임 시작」(또는 작품 선택에서 A)에서 A → 작은 창에 **이어하기(최근 저장 슬롯) / 처음부터 / 시스템 디스크만 부팅** 세 줄이 뜹니다. 저장이 없는 작품은 「이어하기」가 없습니다. ![](img/801_start_sub.png)
8. **정렬(D)**: 제목·원제·연도·제작사·최근 실행·자주 실행·사용자 지정·즐겨찾기 먼저(이전 빌드 샷 `62_list_D.png`).

## ④ 다중 디스크 게임 (핵심)
> 이 장의 화면(작품 선택 오른쪽 「실행」 줄, 실행 방법 목록·편집, 디스크 교체)은 t605b 에서 찍은 것으로 **모두 이전 빌드 샷**입니다. 5b 빌드들에서 이 화면들의 구성은 바뀌지 않았고, 이번 개정에서는 다시 눌러 보지 않았습니다(**미확인: t652 에서의 재시험**). 부가 메뉴에서 「시스템 디스크만 부팅」이 빠진 것만 위 ③-7 대로 달라졌습니다.

디스크가 여러 장이거나 HDD+FD가 섞인 게임은 **「실행 방법」** 에서 어느 드라이브에 무엇을 넣을지 정하고, 게임 중에 **「디스크 교체」** 로 바꿉니다. 먼저 **내 게임이 어느 경우인지**부터 봅니다 — 작품 선택 오른쪽 「실행」 줄에 「(1/2)」「(2/2)」처럼 실행 방법의 개수가 나오고, 아래 설명 줄에 **A: / B: / C:** 로 드라이브별 디스크 이름이 나옵니다.

### 경우 1 — 이미 묶여 있는 게임 (예: 환희담 kitan, FD 2장)
1. 작품 선택 → 한글판 탭 → **kitan**. 오른쪽 「실행」이 「← 데모 먼저 → (1/2)」입니다. ![](img/110_tab_hangul.png)
2. 십자키 **→** 를 한 번 누르면 「FD 부팅 (2/2)」로 바뀌고, 설명 줄이 「A: 환세희담 시스템 디스크 · B: 환세희담 데이터 디스크」가 됩니다. **A 드라이브=시스템, B 드라이브=데이터**로 이미 묶인 실행 방법입니다. ![](img/114_kitan_run2.png)
3. A로 시작 → 처음부터. 게임 메뉴(새롭게 놀기 / 계속 즐기기 / 디스플레이)가 뜹니다. ![](img/115_kitan_boot.png)
4. 게임 중 ≡ → 「디스크 교체」: A 드라이브=kitan-system, B 드라이브=kitan-data 가 들어 있는 걸 확인할 수 있습니다. ![](img/116_kitan_swap.png)

### 경우 2 — HDD+FD 게임 (예: 나디아, HDD 1장 + FD 2장)
**폴더에 HDD와 FD가 같이 있으면 자동으로 묶습니다**(HDD 부팅 + FD 1장을 A 드라이브에 + FD 전부를 「교체 목록」에). 나디아의 자동 실행 방법 이름이 「HDD 부팅 (FD 부착)」 입니다. 아래는 **내가 직접 새로 묶는 법**(자동 묶음이 마음에 안 들 때)입니다 — 틀을 고르면 칸이 **자동으로 채워집니다**.
1. 작품 선택 → **원판 일본어(또는 전체) 탭 → nadia**. 오른쪽 「실행」이 「HDD 부팅 (FD 부착) (1/1)」입니다. ![](img/92_after_esc1.png)
2. **S** → 「실행 방법」 화면. 지금은 「★ 원판 일본어 [자동]」 하나뿐(자동 판정, 항목 정의 없음). ![](img/81_nadia_runlist.png)
3. **「+ 새 실행 방법」** 에서 A → 틀 목록이 나옵니다: 1 HDD 단독 / **2 HDD+FD 부착** / 3 독립 FD 부팅 / 4 다장+교체 / 5 CD+내장 DOS / 6 데모 먼저 / 7 원판·한글판 변형(글꼴) / 8 설치 필요(HDD 생성) / 지금 배치 복제 / **맨 아래 「코드로 넣기」(공유 코드, 아래 ⑧)**. ![](img/45_new_run.png)
4. **「2 HDD+FD 부착」** 을 고르면 편집 화면이 열립니다. **디스크 A=FD 첫 장(`Disk A.hdm`) · 디스크 C=hdi · 부팅 대상=C · 교체 목록=FD 2장**이 자동으로 들어 있습니다. ![](img/206_edit_t2.png)
   ![](img/207_edit_swaplist.png)
5. 칸을 손으로 바꾸고 싶으면 **디스크 A** 칸으로 내려가 A를 누르면 「디스크 A 고르기」 화면이 열립니다. 이 게임 폴더 안의 FD 이미지만 보입니다. ![](img/84_disk_pick.png)
6. 디스크 A 칸에 `(Disk A).hdm` 이 들어갔습니다. 같은 방식으로 **디스크 B**에 `(Option Disk).hdm` 을 넣을 수 있습니다. ![](img/90_A_picked.png)
7. **S = 저장**. 「저장했습니다: HDD 부팅 (FD 부착)」가 뜨고 오른쪽 상세에 디스크 A / 디스크 C / 부팅 C / 교체 0장이 표시됩니다. ![](img/91_after_S.png)
8. B(뒤로)로 작품 선택에 돌아와 nadia에서 A → 「이어하기/처음부터/시스템 디스크만 부팅」 중 **처음부터**(③-7 의 같은 창). ![](img/93_nadia_start_dialog.png)
9. 게임이 뜹니다(처음 몇 초 「글꼴 'anex86.bmp'를 찾지 못해 기본 글꼴」 안내가 뜰 수 있음 → ⑦). ![](img/94_nadia_boot_25s.png)
10. **게임 중 디스크 바꾸기**: 화면 왼쪽 아래 ≡ → 일시정지 메뉴 → **디스크 교체**(일시정지 메뉴는 아래 ⑥). ![](img/08_pause_menu.png)
11. 「디스크 교체」 화면에서 바꿀 드라이브를 고릅니다(A 드라이브 = 지금 들어 있는 디스크, B 드라이브 = 비어 있음). ![](img/97_nadia_disk_swap.png)
12. B 드라이브에서 A → 「B 드라이브에 넣을 디스크」 목록에서 디스크를 골라 A. ![](img/98_swap_pick.png)
13. 화면 위에 「B 드라이브 : Fushigi no Umi no Nadia (Disk A)」 안내가 뜨면 교체 성공입니다. ![](img/100_swap_done.png)

**교체 목록**(실행 방법 편집 화면의 「교체 목록」 칸): **FD가 여러 장이면 자동으로 채워집니다**(위 207 샷). 직접 더하려면 「+ 디스크 추가(이미지 고르기)」. 이 목록의 디스크가 게임 중 「디스크 교체」에 나옵니다. ![](img/104_swaplist_enter.png)
- **⚠ 미확인**: 자동으로 채운 목록으로 나디아를 실제로 시작해 게임 중 두 장째로 바꿔 보는 것은 못 해 봤습니다.
- **⚠ 알려진 현상**: HDD+FD 를 같이 켜면 PC-98 의 부팅 장치 고르는 메뉴(NEC 부트 메뉴)가 한 번 뜰 수 있습니다. 거기서 하드 디스크를 고르면 이어집니다.
- 시험으로 나디아에 「HDD 부팅 (FD 부착)」 실행 방법이 하나 저장돼 있을 수 있습니다. 되돌리려면 그 실행 방법에서 D(메뉴) → 삭제, 또는 부가 메뉴의 「원본 디스크로 초기화」.

### 경우 3 — 실행 파일·실행 인자 칸 (내장 DOS 로 시작하는 작품용)
실행 방법 편집 화면 맨 아래의 **「실행 파일」·「실행 인자」** 두 칸. ![](img/208_edit_exe.png)
- **실행 파일**: 값 「자동」 에서 A → 「실행 파일 고르기」 화면에서 **디스크 이미지 안의 파일**을 고릅니다. 맨 위 「(DOS 프롬프트로 시작 / 아무것도 실행하지 않음)」 은 프롬프트에서 멈추게 합니다. ![](img/209_exepick.png)
- **실행 인자**: 고른 실행 파일에 붙일 인자(OSK 로 입력). 없으면 「없음」.
- 이 두 칸은 **내장 DOS 로 시작하는 작품(CD+DOS 등)에만 적용**됩니다.
- ⚠ 이 화면에서 고른 뒤 **게임이 실제로 그 파일로 시작하는 것**은 실기에서 못 해 봤습니다(미확인). 고른 값은 B 로 나갈 때 「버립니다」 확인창이 뜨고 S 로 저장해야 남습니다.

### 작업 사본 · 초기화 · 원본 없음
- 큐하치는 **원본 이미지를 건드리지 않고** 작업 사본에 기록합니다. 원본이 사라지면 실행할 때 「원본 이미지가 없습니다」 안내가 뜹니다(코드 기준, 미확인).
- 부가 메뉴 「원본 디스크로 초기화」 를 하면 작업 사본을 버리고 원본에서 다시 만듭니다. 쓰던 사본은 **`.bak` 으로 남습니다**(미확인: `.bak` 파일은 눈으로 확인 못 함).

### 한눈에 보는 규칙
- **드라이브 이름**: A, B = 플로피(FD), C = 하드(HDD), CD. 보통 **부팅 대상**은 하드가 있으면 C, FD 게임이면 A.
- 실행 방법이 여러 개면 작품 선택에서 **←→ 로 고르고** A로 시작합니다(「(1/2)」 표시).
- **HDD+FD가 섞이면 틀 2번, FD만 여러 장이면 틀 4번(다장+교체)**. FD가 여러 장이면 1·2·3·6번 틀이 교체 목록을 자동으로 채웁니다.
- 편집 화면의 키: ↑↓ 칸 / ←→ 값 / **A 고르기** / **S 저장** / **D 시험(실행해 보기)** / Tab 기본 지정 / B 나가기. ![](img/50_multidisk_wizard1.png)
- 이름 칸에서 A → 이름 목록(한글판·원판 일본어·CD 모드·HDD 부팅·FD 부팅·데모 먼저·다장 디스크·설치 필요·내 실행 방법·직접 입력). 빈 칸이 있으면 아래에 「오류: 부팅 대상 A 칸이 비어 있음」처럼 이유가 뜹니다. ![](img/51_multidisk_wizard2.png)

## ⑤ 설정 (메인메뉴 → 설정)
**설정**은 다섯 줄의 허브입니다(확인함): **화면 / 소리 / 조작 / 시스템 / 메뉴 꾸밈**. 게임 중에는 ≡ → 일시정지 메뉴 → **설정** 으로 같은 허브가 열립니다. ![](img/900_hub.png)

**적용 범위**(화면·소리·조작·시스템 각 화면의 맨 위 줄): **전역**(모든 작품) / **이 작품**(이 작품만). 「이 작품」을 고른 뒤 값을 바꾸면 **바꾼 줄만 이 작품에 따로 저장**되고 나머지는 전역을 따라갑니다. 따로 저장된 줄에는 **앞에 ●** 가 붙고 오른쪽에 「● 개별 설정 있음」이 보입니다. 되돌리는 법 두 가지: **그 줄에서 △(=X 버튼) = 이 줄만 전역으로**, 또는 이 작품 범위 맨 아래 **「개별 설정 초기화」**(확인창 후 ●를 모두 지움). 화면 아래 「D:출하 시 설정」(키보드 D) 은 기본값으로 되돌림, B는 취소(화면 설정은 바꾸기 전 값으로 되돌림). *(이 작품 범위 화면은 이번에 다시 못 찍어 이전 빌드 샷: `506_this_game_clean.png` · `508_fps_off_marked.png` · `509_reset_row.png` · `516_reset_confirm.png`)*

1. **화면**: **프리셋**(기본(끔) / 부드러운 CRT / 진한 CRT / 내 프리셋 / 「+ 지금 값을 저장」)을 ←→ 로 고르면 바로 적용되고, 이어서 **비율**(4:3 · 16:10 · 정수배) · **필터**(sharp · nearest) · **주사선 · 마스크 · RGB 번짐 · 빛 번짐 · 곡면** 슬라이더 · **FPS / Speed 표시**(OFF/ON). 아래쪽 「미리보기」 창이 바꾼 값을 바로 보여 줍니다. ![](img/901_screen_hub.png)
   - **효과 켜는 법**: 주사선·마스크·번짐 줄로 내려가 →(오른쪽)으로 값을 올립니다. 효과를 켠 모습은 이전 빌드 샷 `70_fx_on_preview.png`.
   - **프리셋 저장·삭제**(이전 빌드 샷 `530_preset_plus_entry.png` → `531_preset_saved_user1.png` → `532_preset_delete_confirm.png`): 「+ 지금 값을 저장」에서 A → 지금 값이 「내 프리셋」으로 저장됩니다. 지울 땐 내 프리셋에서 D → 확인창(지금 화면 값은 그대로 남음). 이번 t652 에서는 프리셋 고르기·저장·삭제를 **눌러 보지 못했습니다(미확인)**.
2. **소리**: BGM 음량 · 효과음 음량(OFF~최대 8) · **소리 버퍼**(512 / 1024 / 2048 / 4096, **다음 시작부터 적용**, 전역 범위에만 있음). ![](img/902_conf_sound.png)
3. **조작**: **조작 설정**(패드 배정 화면 입구, 아래 ⑥) · **배속 배율**(x2~x8) · **배속 방식**(홀드/토글/둘 다) · **배속 중 소리**(끔/빠르게/음높이 유지) · **배속 표시** · **오버레이 버튼 표시**(게임 화면 왼쪽 아래 버튼 5개를 보일지). ![](img/903_conf_control.png)
4. **시스템**: **부팅 시퀀스**(켬/끔) · **한글 글꼴 · 일본어 글꼴 · 언어**(한국어/English/にほんご, 전역 범위에만 있음). **한글/일본어 글꼴 줄에 커서를 두면 오른쪽 아래에 「지금 적용: <글꼴 이름> (<출처>)」 한 줄이 보입니다**(확인함). 출처는 **실행 방법**(실행 방법의 글꼴 칸) / **작품 언어 기본**(작품 언어가 정한 글꼴) / **시스템**(설정의 기본 글꼴) 중 하나. 예: 「지금 적용: kyuhachi_font (시스템)」. ![](img/812_font_kr_row.png)
   - 첫 줄(전역/이 작품)에서 「이 작품」을 고르면 글꼴·언어·소리 버퍼 줄은 숨겨지고(전역 전용), 그 줄 대신 이 작품에 적용되는 값만 보입니다.
5. **메뉴 꾸밈**(메뉴 글자 점멸 효과): **단위**(글자마다 …) · **세기** · **속도** · **광량(번짐)** · **색**(녹색 …)을 ←→ 로 바꿉니다. 메뉴 글자가 은은하게 깜박이는 효과이며 게임 화면에는 영향이 없습니다. 이 샷은 값을 바꾸지 않은 첫 화면(단위=글자마다, 세기 4, 속도 3, 광량 6, 색=녹색)입니다. ![](img/908_shim.png)
6. **세이브 관리**(메인메뉴, 확인함): 작품 하나에 **다섯 칸 — 자동 / 퀵 / 일반 1 · 2 · 3**. 비어 있는 칸은 회색 「(비어 있음)」, 채워진 칸은 저장 시각이 보이고 오른쪽에 **저장 때 화면 그림 · 저장 시각 · 상태 파일 크기**가 나옵니다. **A(Enter)=불러오기, D=삭제**, B=취소. 게임 중 일시정지 메뉴의 「저장 (슬롯 고르기)」도 같은 칸 화면입니다. ![](img/909_save_slots.png)

## ⑥ 패드 배정 (설정 → 조작 → 조작 설정)
화면 위 제목에서 보이는 탭이 셋 있습니다. **L·R 어깨 버튼(키보드 Q·E)** 으로 넘깁니다(확인함: 키보드 E 로 넘김, 패드 어깨 버튼으로 넘기는 것은 미확인).
1. **패드 버튼 탭**: 왼쪽에 **적용 범위 / 결정 버튼 / → ↓ ← ↑ 버튼 / START / 왼쪽·오른쪽 어깨 / SELECT / 십자키** 줄. 맨 위 **결정 버튼**을 ←→ 로 **→(A)** 또는 **↓(B)** 로 고릅니다(일본식=오른쪽 버튼이 결정, 서양식=아래 버튼이 결정). 각 줄에서 A(Enter)를 누르면 **PC-98 키 고르기**가 열립니다. **오른쪽에는 16개 버튼(L2·L1·UP·LF·RG·DN·L3·SE / R2·R1·X·Y·A·B·R3·ST)이 지금 어떤 키·기능에 배정돼 있는지 한눈에 보이는 표**가 있습니다(예: A=SPACE, B=ESC, Y=CAPS, X=메뉴 열기, R2=배속 누름, L3=배속 토글, ST=RET). 아래에 「SELECT+START = 메뉴 열기(고정)」. ![](img/904_pad_tab_arrows.png)
2. **핫키 탭**(SELECT 를 누른 채 누르는 조합): **메뉴 열기 SELECT+START(고정)** · 퀵 저장 SELECT+R1 · 퀵 불러오기 SELECT+L1 · 화면 키보드 SELECT+X · 스크린샷 SELECT+R3 · 다음 디스크로 교체 SELECT+R2 · FPS 표시 켜고 끄기(기본 배정 없음). 줄에서 **A(Enter) → 「누를 버튼 잡기」**: 안내가 뜨면 **원하는 조합을 누르면** 배정되고, 안 누르면 시간이 지나 취소됩니다. **D=기본값**. 저장 위치는 전역 설정입니다. ![](img/905_pad_tab_hot.png)
3. **추가 버튼 탭**: 기본 배정 밖의 **키보드·패드 버튼을 새로 등록**해 키·기능을 줍니다. 「+ 버튼 등록」에서 A → 버튼을 누르면 등록, 그다음 키·기능 배정. **운영체제가 쓰는 버튼(홈·뒤로 등)은 잡히지 않습니다.** D=지우기, L=핫키 탭. ![](img/906_pad_tab_ext.png)
4. **키 고르기(화면 키보드)**: 배정 줄에서 A → 키 목록이 열려 **PC-98 키를 고릅니다**(PC-98 키 목록 화면 입구는 확인함, **이번엔 안쪽 화면을 못 찍음 — 이전 빌드 샷 `539_pad_picker_fn_menu.png` · `540_pad_picker_quick_save.png`**). 게임 중 ≡ → **키보드**에서 **PC-98 키 보내기 / 화면 키보드 / 키보드 버튼 표시 / 키보드·배속 셰이더 / 스크린샷**(미확인: 이번엔 안 눌러 봄).
5. 5b-4 에서 「조작 안내」 화면의 ○ × □ △ 표기를 노바 표기(→(A) ↓(B) ←(Y) ↑(X))로 고쳤습니다. 그 밖의 안쪽 화면에 PS 식 기호가 남아 있으면 **○=A · ×=B · □=Y · △=X** 로 읽으세요.

3. **≡ → 일시정지 메뉴(여덟 줄, 확인함)**: **이어하기 / 저장(슬롯 고르기) / 불러오기 / 디스크 교체 / 설정 / 키보드 / 메인 메뉴로 / 끝내기**. 예전의 「화면 설정」「소리·패드·배속 설정」「PC-98 키 보내기」「스크린샷」 줄은 **설정**·**키보드** 안으로 들어갔습니다. ![](img/915_pause_menu.png)
4. **메인 메뉴로**: 확인창 「저장하지 않은 진행은 사라집니다」가 뜹니다. 처음엔 「아니오」에 커서가 있으니 십자키 **←** 로 「예」를 고르고 A, 또는 「예」를 터치(빌드 4 부터 확인창 터치 됨; 이전 빌드 샷 `18_main_menu_again.png`).
5. 저장은 일시정지 메뉴의 「저장 (슬롯 고르기)」, 불러오기는 「불러오기」 또는 메인메뉴 → 세이브 관리. **퀵 저장·퀵 불러오기는 핫키(SELECT+R1 / SELECT+L1, ⑥-2)** 로도 됩니다(핫키 동작은 Windows 입력 시험으로 확인, **노바 실기 입력은 미확인**).

## ⑧ 실행 방법 공유 코드 (KHX1)
누가 맞춰 둔 **실행 방법 하나**(게임 이름·드라이브별 디스크·부팅 대상·교체 목록·실행 파일·글꼴·다음 단계 등)를 **문자열 하나(`KHX1-…`)로 주고받습니다.** 화면·소리·패드 설정, 세이브, 경로·명령은 담기지 않습니다. 디스크는 파일 이름이 아니라 **내용(sha1)** 으로 가리켜서, 받는 쪽 폴더에서 같은 디스크를 찾아 넣습니다.
- **만들기**: 작품 선택 → **S**(실행 방법) → 실행 방법에서 **D(메뉴) → 「공유 코드 만들기」** → 코드가 표시되고 클립보드에 복사되며 `games\<작품>\<이름>.khx` 파일로도 저장됩니다.
- **넣기**: 작품 선택 → S → 「+ 새 실행 방법」 → 틀 목록 **맨 아래 「코드로 넣기」** → 붙여넣기 / `.khx` 파일 고르기 / 화면 키보드로 입력 → **미리보기**(게임 이름 · 실행 방법 이름 · 디스크 찾음 n/n)를 보고 확인.
- 못 찾은 디스크는 「○○ 디스크가 없습니다」 목록으로 알려 주고 그 칸은 비운 채 저장할지 묻습니다.
- **⚠ 미확인**: 이 장은 설계·코드 기준 설명이며 **노바에서 만들기/넣기를 눌러 보지 못했습니다**(Windows 에서 왕복 시험만 통과). 메뉴 이름이 실제 화면과 조금 다를 수 있습니다.

## ⑨ 안 될 때 · 시작을 막지 않는 경우
| 증상 | 해 볼 것 |
|---|---|
| 시작할 때 「글꼴 'anex86.bmp' 를 찾지 못해 기본 글꼴로 실행합니다 (res\fonts)」 | 글꼴 파일이 없다는 안내입니다. **글꼴이 없어도 멈추지 않고 기본 글꼴로 그대로 시작**합니다(확인함: 나디아 1차 판, t605b 에서도 글꼴 없는 작품 정상 시작). 글자가 이상하면 `Kyuhachi\fonts` 에 글꼴 BMP를 넣거나, 설정 → 시스템의 한글/일본어 글꼴을 바꿉니다(「지금 적용」 줄로 무엇이 쓰이는지 확인). |
| 글자가 깨짐·외계어 | 위와 같음. 작품 실행 방법의 「글꼴」 칸이 「자동(목록 기본)」인지도 확인 |
| 화면이 까맣다 | 시작 후 수십 초 기다립니다(나디아는 25초쯤). 계속 까맣으면 일시정지 메뉴 → 설정 → 화면에서 효과를 끄고, 안 되면 메인메뉴 게임 시작 → 시스템 디스크만 부팅 |
| 다중 디스크 게임이 중간에 멈춤/「디스크를 넣어라」 | ④의 실행 방법에서 디스크 칸(A/B)이 채워졌는지 확인, 게임 중 ≡ → 디스크 교체로 B 드라이브에 다음 디스크 |
| 작품이 목록에 없다 | ② 폴더 위치(`games\<게임>\`) 확인 → ③ 「게임 폴더 다시 검색」. **미분류 탭**도 확인 |
| 한글판/원판이 잘못 분류됨 | 부가 → 이 작품 설정 → 언어 지정 |
| 되돌리고 싶다 | 부가 → 「원본 디스크로 초기화」, 설정은 D(출하 시 설정) 또는 「개별 설정 초기화」 |
| 첫 실행에서 작품이 하나도 안 보임 | 「모든 파일에 액세스」 권한을 허용했는지(① -1) |

**시작을 막지 않는 것(확인함: 글꼴)**: 글꼴 BMP 가 하나도 없거나 이름으로 글꼴을 못 찾아도 **막지 않고 번들·내장 글꼴로 시작하며 화면에 안내**합니다. 「마우스 필수」 작품도 목록에서 **막히지 않고 표시만** 됩니다(코드 기준, 미확인). 이미지 파일이 없거나 열 수 없는 경우, 부팅 가능한 디스크가 하나도 없는 경우 등은 시작이 막히고 안내가 뜹니다(이유 안내 문구는 코드 기준 — 부팅 디스크가 없는 작품을 DOS 프롬프트로 여는 처리는 **미확인**).
