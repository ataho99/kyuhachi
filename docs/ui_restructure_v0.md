## ① 화면 나무: 지금 → 바꾼 안

### 원칙 3개
1. 깊이 최대 3단(모달 제외). 지금 최대 7단(편집의 자동 입력 단계 글자 입력).
2. 같은 설정은 한 곳에만. 전역/작품별은 **같은 화면에서 맨 위 토글 하나**(탭마다 따로 두지 않는다)로 바꾼다.
3. 작품을 시작하는 길은 하나(홈에서 ○), 설정 화면은 하나(탭 4개).

## ② 헤맴 Top 10 중 5~10번 — 푸는 법 한 줄씩

(1~4번은 t52e 에서 고침.)

5. **배속 입력 5종과 설정의 관계** — 설정 > 조작·배속 탭 아래쪽에 「입력 → 동작」 표를 늘 보여 준다(F11·R2 = 누르는 동안 배속 / ScrollLock·Alt+F11·L3 = 켜기·끄기 / 방식 설정은 어느 입력을 켜고 끄는지 표 칸 색으로 표시). 「홀드 전용」이면 토글 키 행이 회색으로 꺼진다(지금 `미확인`인 동작을 화면에서 바로 알 수 있게).
6. **화면 설정 세 곳(메뉴·Alt 단축키·창 끌기)** — 정본은 설정 > 화면 탭 하나. Alt 단축키·창 끌기는 결과를 **항상 현재 범위(전역/작품) 값에 쓰고** 화면 탭이 그 값을 보여 준다. 화면 탭 맨 아래 한 줄에 해당 단축키를 적는다(Alt+1/2/3·S·↑↓·[ ]). 전체화면 행 추가(지금 메뉴에 없음). 메뉴 안에서도 Alt 조합이 먹도록 한다(지금은 무시). 창 배율 행 = 프리셋, 끌어서 만든 크기 = 「사용자 지정」 값으로 표시.
7. **편집 7단, 「완료」≠저장** — 편집을 3단으로 줄이고(가로 탭), 글자·파일은 모달. 하위 목록의 「완료」를 없앤다. 대신 편집 화면 위에 「● 저장 안 됨」 표시를 늘 보이고, 저장은 □ 하나, × 는 저장 안 된 변경이 있을 때만 「저장 / 버림 / 계속」 확인 1회.
8. **적용 범위 토글 세 곳, 작품별 값이 전역을 가리는 게 안 보임** — 토글은 설정 화면 맨 위 한 곳([전역 | 이 작품]). 「이 작품」일 때 값이 전역과 다른 행에는 ◆ 표식 + 전역값을 흐리게 옆에 적고, 화면 아래에 「이 작품이 전역과 다른 항목 N개 — △:모두 전역으로」. ○ 로 「적용값」(지금 부가 3단 안쪽)으로 바로 간다.
9. **작품 시작까지 3번 / 시스템 디스크만 부팅은 1번** — 홈에서 ○ = 시작(저장이 있으면 팝업 1회: 이어하기 · 처음부터 · 시스템 디스크만 → 최대 2번 누름, 저장 없으면 1번). 「시스템 디스크만 부팅」을 부가에서 빼서 같은 팝업의 세 번째 선택지로 옮긴다 → 시작하는 길이 한 곳, 누름 수가 같은 규칙.
10. **같은 키가 화면마다 다른 뜻** — ③ 키 통일표로 모든 화면의 의미를 한 줄로 고정. 화면별 도움말 줄은 표에서 자동으로 만든다(화면마다 손으로 쓰지 않음).

## ③ 통일 키표

규칙: 아래 뜻은 **모든 화면·모든 모달에서 같다**. 화면에 해당 동작이 없으면 아무 일도 안 한다(다른 뜻으로 재활용 금지). 도움말 줄은 이 표에서 만든다.

| 키 (패드 / 키보드 / 터치) | 뜻 | 예외·이유 |
|---|---|---|
| ○ (결정 방식에 따라 B 또는 A / Enter · Space / 탭) | **결정** — 선택·열기·시작·값 입력. 값 행은 ←→ 로 바꾸고 ○ 는 「입력 화면 열기」일 때만 | 없음. (홈 ○ = 시작은 「결정」의 한 경우) |
| × (A 또는 B / Esc · Backspace / 뒤로·바깥 탭) | **뒤로** — 한 단 위로. 저장 안 된 변경이 있을 때만 확인 1회 | ① 홈의 × = 종료 확인(안드로이드 「뒤로」 관례) — 도움말 줄에 `×:끝내기` 로 표시. ② 글자 입력 모달의 Backspace = 「한 글자 지움」(텍스트 입력 관례, Esc/× 는 취소) |
| △ (Y / D / 길게 누름) | **보조 메뉴** — 그 화면의 부가 동작 목록을 연다(정렬·삭제·위로·아래로·복제·출하값·시험·…) | 지금 화면마다 달랐던 직접 동작(△=삭제·정렬·시험·위로·출하값)은 전부 보조 메뉴 안으로. 예외: 글자 입력 모달의 △ = 대소문자(관례, 한 손으로 쓰는 키보드) |
| □ (X / S / 저장 버튼) | **저장 · 적용** — 편집·설정에서 확정. 슬롯 화면에서는 「이 슬롯에 저장」 | 지금의 □ 뜻(편집 열기·실행 방법·비우기·지움·삭제) 은 모두 폐지 → 보조 메뉴로. 글자 입력의 「지움」 □ 는 Backspace + 보조 메뉴 「모두 지움」 |
| START (패드) | **시작 · 완료** — 홈에서 선택 작품 시작, 모달에서 완료 | ○ 와 겹치지 않게(지금은 START=○). 입력 모달의 「완료」가 SEL 에서 이쪽으로 이사 |
| SELECT (패드) / Tab | **메뉴** — 홈에서 SEL 메뉴(설정·작품 관리·부가·끝내기) 열기. 다른 화면에서는 같은 메뉴의 「현재 위치」 | 지금 SEL 의 다른 뜻(편집 기본 지정, 아래로, 입력 완료)은 폐지 |
| L / R (Q / E / 탭 헤더 탭) | **탭 이동** — 탭이 있는 화면에서 좌우 탭. 탭이 없으면 무시 | 파일 고르기의 L/R(위치 전환) 은 「드라이브 탭」으로 같은 의미 |
| ←→ | 값 바꾸기(값 행) · 슬롯/방식 이동 | |
| F12 (키보드) | **메뉴 토글** — 게임 중 일시정지 열기·닫기. 메뉴 안에서 닫기 | 홈에서는 아무 일 없음(지금은 ×처럼 종료 확인을 열었음) |
| Enter · Space (키보드) | 메뉴가 열려 있을 때만 ○. 게임 중에는 게임 키 | 게임 키와 충돌하기 때문 |
| Backspace (키보드) | × 와 같음(입력 모달 제외) | 위 ② |
| Esc (키보드) | × | |
| Alt 조합 (키보드) | 게임 화면 단축키. **메뉴 안에서도 같은 결과를 낸다**(설정 값에 반영) | 지금 메뉴에서 무시되던 것을 풀되, 메뉴 글자 입력 중에는 막는다(한글 입력과 충돌) |

설정 화면의 값 변경은 **미리보기 + □ 확정, × 원복**으로 통일(지금 화면 설정만 ×가 되돌림, 동작 환경 설정은 즉시 저장) → 슨상 결정 2번.

## ④ 터치·패드(안드로이드) 기준

가정: 패드 주, 터치 보조. 노바 실제 화면 크기·dpi 는 확인하지 못했다(숫자는 계산식과 예시로만 쓴다).

**1. 터치 대상 크기**
- 손가락으로 누르는 항목은 **물리 크기 7mm 이상**(탭 헤더·토글·작은 버튼은 9mm 이상, Android 권장 48dp ≈ 9mm). 항목 사이 간격은 가운데를 잘 맞추기 위해 눈에 보이는 크기보다 **히트 영역을 위아래 4가상px 넓힌다**(보이는 모양은 그대로).
- 지금 메뉴는 가상 640×400 에서 행 높이 20 가상px. 화면 표시 높이가 H mm 이면 한 행 = 20 × H/400 mm. 예: 표시 높이 68mm(5.5인치 16:9 가정) → 행 3.4mm — **손가락으로는 못 누른다**. 필요한 가상 높이 = 7mm × 400 / H: 같은 예에서 약 41 가상px.
- 대응: 터치로 메뉴를 쓰는 기기에서는 「메뉴 확대」 모드(행 높이 ≥ 41 가상px = 한 화면 행 수 약 7개, 스크롤 대신 L/R 페이지) 를 쓴다. 패드만 쓰면 지금 크기 유지. 결정 5번.
- 탭 방식: 목록 행은 **첫 탭 = 선택(포커스), 같은 행 두 번째 탭 = ○**(오조작 방지). 탭 헤더·토글·← → 화살표 영역은 한 번 탭으로 바로 동작.

**2. 길게 누름(0.6초, 오버레이 「불러오기」 버튼과 같은 값 유지)을 쓰는 곳** — 이것만:
| 곳 | 길게 누름 = |
|---|---|
